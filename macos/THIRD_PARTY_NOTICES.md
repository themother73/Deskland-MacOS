# Third-party dependencies / Dépendances tierces

## Apple frameworks

Deskscape for macOS uses system frameworks only (AppKit, WebKit, ServiceManagement, IOKit). Nothing is bundled; Apple components keep their own licenses.

## Deskland Preview (upstream)

Theme pages, settings UI, sharing tools and artwork in `web/` come from Deskland Preview (https://github.com/BLEZZ0102/Deskland, GPL-3.0). See upstream's notices for the Windows-only components (Microsoft Edge WebView2, NSIS), which are not part of this macOS port.
